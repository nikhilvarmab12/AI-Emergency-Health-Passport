# 🏥 AI-Powered Emergency Health Passport (AI-EHP)

**A secure, AI-enabled healthcare information system for rapid emergency medical decision support.**

[🌐 Live Application](https://ai-emergency-health-passport.vercel.app) · [💻 GitHub Repository](https://github.com/nikhilvarmab12)

## 📌 About the Project

AI-Powered Emergency Health Passport (AI-EHP) is a full-stack healthcare web application designed to make critical medical information accessible during emergencies.

When a patient is unconscious or unable to communicate, the system provides a way to access essential emergency health information through a QR code and secure access token.

The project aims to improve the availability of important medical information and support faster, more informed emergency medical decision-making.

## ✨ Key Features

* **User Authentication:** Patient registration, email OTP verification, and login.
* **Digital Health Profile:** Store and manage important medical information.
* **Emergency Health Passport:** Organize critical health information for emergency situations.
* **QR Code Access:** Generate and scan QR codes for emergency passport access.
* **Access Control:** Secure access mechanisms for sensitive medical information.
* **QR Revocation:** Revoke emergency access when required.
* **AI Emergency Guidance:** Provide AI-assisted emergency information and guidance.
* **Access History:** Maintain a history of emergency passport access.

## 🔐 Security and Privacy

The application incorporates authentication, password hashing, access controls, and secure configuration practices.

AI-generated information is intended to support decision-making and must not replace professional medical evaluation or emergency medical services.

This project is an academic prototype and is not a substitute for a certified clinical system.
